# Ліхтар Worker

Сервер-посередник для плагіна. Робить дві речі:

- **Сесії «налаштувати з телефона»** — телевізор показує код, телефон надсилає за ним конфіг, телевізор його забирає.
- **Проксі** для джерел без CORS (JacRed, YouTube-фіди, Uafix) замість публічних проксі, які постійно падають.

## Запуск на своєму комп'ютері

```bash
cd worker && npx wrangler dev --ip 0.0.0.0 --port 8787
```

Далі відкрийте <http://localhost:8787> — там сторінка для ручної перевірки всіх ендпоінтів.

Щоб дістатись із телевізора, підключіть його до тієї ж мережі й використайте IP комп'ютера, наприклад `http://192.168.0.70:8787`.

Локально сесії лежать у пам'яті процесу: після перезапуску `wrangler dev` вони зникають, і це нормально.

## Ендпоінти

| Метод | Шлях | Призначення |
|---|---|---|
| `GET` | `/api/health` | Перевірка, що живий; показує тип сховища |
| `POST` | `/api/session` | Телевізор створює сесію → `{code, ttl}` |
| `GET` | `/api/session/:code` | Читання конфігу (телефон і телевізор) |
| `PUT` | `/api/session/:code` | Телефон зберігає конфіг |
| `GET` | `/api/proxy?url=…` | Проксі для дозволених джерел |

## Деплой у Cloudflare

Пам'ять процесу для продакшену не годиться — потрібне KV:

```bash
npx wrangler kv namespace create LIKHTAR
```

Отриманий `id` вписати у `wrangler.toml` (розкоментувати блок `[[kv_namespaces]]`), далі:

```bash
npx wrangler deploy
```

## Обмеження, закладені свідомо

- **Проксі працює лише для відомих доменів.** Без цього списку Worker миттєво став би відкритим проксі, яким скористається хтось сторонній.
- **Код сесії живе 15 хвилин** і складається з символів, які не сплутати на екрані: без `O`/`0`, `I`/`1`, `S`/`5`.
- **Конфіг обмежений 64 КБ** — більше налаштувань плагіна не буває.

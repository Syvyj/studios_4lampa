# Ліхтар Worker

Сервер-посередник для плагіна. Робить дві речі:

- **Сесії «налаштувати з телефона»** — телевізор показує код, телефон надсилає за ним конфіг, телевізор його забирає.
- **Проксі** для джерел без CORS (JacRed, YouTube-фіди, Uafix) замість публічних проксі, які постійно падають.

## Запуск на своєму комп'ютері

```bash
cd worker && npx wrangler dev --ip 0.0.0.0 --port 8787
```

Далі відкрийте <http://localhost:8787> — там сторінка для ручної перевірки всіх ендпоінтів.

Щоб дістатись із телевізора, підключіть його до тієї ж мережі й використайте IP комп'ютера, наприклад `http://192.168.0.70:8787`.

Локально сесії лежать у пам'яті процесу: після перезапуску `wrangler dev` вони зникають, і це нормально.

## Ендпоінти

| Метод | Шлях | Призначення |
|---|---|---|
| `GET` | `/api/health` | Перевірка, що живий; показує тип сховища |
| `POST` | `/api/session` | Телевізор створює сесію → `{code, ttl}` |
| `GET` | `/api/session/:code` | Читання сесії (телефон і телевізор) |
| `PUT` | `/api/session/:code` | Оновлення сесії: `config`, `deck` або `action` |
| `GET` | `/api/proxy?url=…` | Проксі для дозволених джерел |
| `GET` | `/api/qr?text=…` | QR у SVG для екрана телевізора |
| `POST` | `/api/quality` | Пакетна перевірка якості релізів у JacRed |

### Сторінки для телефона

| Шлях | Призначення |
|---|---|
| `/` | Ручна перевірка ендпоінтів |
| `/config?s=КОД` | Налаштування плагіна |
| `/roulette?s=КОД` | Кінорулетка: гортання фільмів свайпами |

`PUT /api/session/:code` оновлює лише передані поля, решта лишається недоторканою — тому телевізор може покласти колоду, а телефон паралельно зберегти налаштування, і вони не затруть одне одного.

## Деплой у Cloudflare

Пам'ять процесу для продакшену не годиться — потрібне KV:

```bash
npx wrangler kv namespace create LIKHTAR
```

Отриманий `id` вписати у `wrangler.toml` (розкоментувати блок `[[kv_namespaces]]`), далі:

```bash
npx wrangler deploy
```

## Обмеження, закладені свідомо

- **Проксі працює лише для відомих доменів.** Без цього списку Worker миттєво став би відкритим проксі, яким скористається хтось сторонній.
- **Код сесії живе 15 хвилин** і складається з символів, які не сплутати на екрані: без `O`/`0`, `I`/`1`, `S`/`5`.
- **Конфіг обмежений 64 КБ** — більше налаштувань плагіна не буває.

## Ліхтарик і локальна модель

`POST /api/ai` приймає `{query}` і повертає `{titles: [[назва, рік], …]}`.
Питання ставиться зі сторінки `/ask?s=КОД` на телефоні, а шукає назви в TMDB
телевізор — ключ до бази є саме в нього, і там же відсіюються вигадані фільми.

Модель задається змінними у `wrangler.toml`:

```toml
[vars]
OLLAMA_URL = "http://100.114.237.121:11434"
OLLAMA_MODEL = "gemma4:e4b"
```

> **Увага для деплою.** Адреса вказує на домашню мережу, тож `/api/ai` працює,
> поки Worker крутиться на цьому ж комп'ютері. У Cloudflare цей хост недосяжний —
> знадобиться тунель до Ollama, інакше ендпоінт відповідатиме `ai_unreachable`.

Модель вигадує фільми — це нормально для невеликої локальної. Запобіжник
не в промпті, а в перевірці: кожну назву телевізор шукає в TMDB і викидає ту,
якої там немає або в якої не збігається рік.

# Промт: набери топ року з TMDB і склади картки

Найкоротший шлях: модель сама бере список із TMDB, сама шукає матеріал і
сама пише файли в `inbox/` — жодних пачок і експорту.

## Що взяти й куди залити

**2026 — поле майже порожнє**, більшість назв нові. Заливати звичайно:

```bash
python3 tools/import-cards.py inbox/*.json
python3 tools/audit-cards.py
```

**2025 — уже наповнений** (фільми 93% із джерелом, серіали 75%). Тут прогін
переважно перезаписує наявне, а свіжа картка легко виявиться біднішою за
ту, що вже є. Тому заливати тільки нові назви:

```bash
python3 tools/import-cards.py --only-new inbox/*.json
python3 tools/audit-cards.py
```

## Про поріг

TMDB має два різні фільтри, і плутати їх не варто:

- `vote_count.gte` — скільки людей проголосувало
- `vote_average.gte` — сама оцінка від 0 до 10

Оцінка без кількості голосів обманює: фільм із трьома голосами й середнім
9.5 стоятиме вище за все. Тому поріг завжди ставимо парою — оцінка **і**
мінімум голосів.

## Промт (копіювати цілком)

Перед копіюванням заміни рік і поріг у двох посиланнях нижче, якщо треба
інші. Готові варіанти:

- **2026, усе помітне:** `primary_release_year=2026` + `vote_count.gte=20`
- **2025, лише добре оцінене:** `primary_release_year=2025` + `vote_count.gte=100&vote_average.gte=6.5`

```
Робоча тека: /Users/admin/Projects/studios_4lampa-dev

Завдання: візьми з TMDB топ фільмів і серіалів 2025 року — рейтинг не
нижче 6.5 при щонайменше 100 голосах — і склади для кожного картку для
української медіатеки. Перші 60 за популярністю.

TMDB API-ключ: 4ef0d7355d9ffb5151e987764708ce96

  фільми:
  https://api.themoviedb.org/3/discover/movie?primary_release_year=2025&vote_average.gte=6.5&vote_count.gte=100&sort_by=popularity.desc&language=uk&api_key=КЛЮЧ

  серіали:
  https://api.themoviedb.org/3/discover/tv?first_air_date_year=2025&vote_average.gte=6.5&vote_count.gte=100&sort_by=popularity.desc&language=uk&without_genres=10763,10764,10767&api_key=КЛЮЧ

Для кожної назви знайди матеріал: стаття у Вікіпедії будь-якою мовою,
сторінка студії чи стримінгу, фахова преса, рецензії. Перевір, що стаття
саме про цю назву — збігаються рік, тип (фільм чи серіал) і назва. Пошук
завжди щось повертає, і це «щось» часто інший твір: на «Друзі та сусіди»
колись видало статтю про «Друзі», на «The Huntsman» — про «Snow White and
the Huntsman».

Склади JSON і запиши у файли inbox/2025-фільми.json та
inbox/2025-серіали.json як масиви карток. Нічого іншого в проєкті не чіпай.

Оцінки: 0 — немає, 5 — дуже багато. Складність 1-5.

# Правила

1. Сюжет, фінал і факти — тільки з того, що ти справді прочитав. Не
   знайшов — порожній рядок або порожній масив, і "source": null.
   Порожнє поле нормально, вигадане — брак.
2. Не пиши в поле пояснень, чому не знайшов. Порожнє — це "" і все.
3. Оцінки й настрій — твоє судження, їх став завжди.
4. "worth" — про САМ ТВІР: тон, чим вирізняється серед подібного.
   "for"/"not_for" — про аудиторію. Найчастіша помилка: worth починається
   зі звернення до глядача й переказує for іншими словами.
     Погано: «Якщо вам подобаються історичні драми, фільм може сподобатися.»
     Добре:  «Камерна драма, що тримається на одному довгому діалозі.»
5. Опис оцінки пояснює причину, а не повторює бал. Не «Помірна складність»,
   а «Заплутано через стрибки в часі».
6. Мова — жива українська: «глядач», не «глядатель»; «захопливий», не
   «захоплюючий»; без «рекомендується для» і без «шедевр»/«маст-вотч».
```

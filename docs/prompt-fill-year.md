# Промт: набери топ року з TMDB і склади картки

Найкоротший шлях. Модель сама бере список із TMDB, сама шукає матеріал і
сама пише файли — жодних пачок і експорту.

Працює тільки для назв, яких у базі ще немає: там нема чого зіпсувати.
Тому пише вона в `inbox/`, а не в `cards/` — звідти картки заходять уже
через нашу перевірку.

## Кроки

1. Новий чат, промт нижче.
2. Коли скаже «готово»:

```bash
cd /Users/admin/Projects/studios_4lampa-dev
python3 tools/import-cards.py inbox/*.json    # перевірка + заливка
python3 tools/audit-cards.py                  # чи не взято чужу статтю
```

Оцінки: 0 — немає, 5 — дуже багато. Складність 1-5.

# Правила

1. Сюжет, фінал і факти — тільки з того, що ти справді прочитав. Не
   знайшов — порожній рядок або порожній масив, і "source": null.
   Порожнє поле нормально, вигадане — брак.
2. Не пиши в поле пояснень, чому не знайшов. Порожнє — це "" і все.
3. Оцінки й настрій — твоє судження, їх став завжди.
4. "worth" — про саму річ (тон, чим вирізняється), "for"/"not_for" — про
   аудиторію. Якщо "worth" можна видалити й нічого не загубиться — перепиши.
5. Опис оцінки пояснює причину, а не повторює бал. Не «Помірна складність»,
   а «Заплутано через стрибки в часі».
6. Мова — жива українська: «глядач», не «глядатель»; «захопливий», не
   «захоплюючий»; без «рекомендується для» і без «шедевр»/«маст-вотч».

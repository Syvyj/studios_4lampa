# Промт: редагування «Чи варто дивитись?» у готових картках

На відміну від наповнення бази, тут не бракує матеріалу — картки вже мають
`watch`/`mood`/оцінки. Завдання не шукати, а прибрати два конкретні дефекти:
тавтологію між полями та випадкові перекручення слів. Тому пачки більші
(40 карток) і жодного пошуку в мережі не треба.

## Кроки

```bash
python3 tools/make-review-batches.py --size 40
```

Далі — новий чат, промт нижче, прикріпити одну пачку з `review/batch-001.json`.
Відповідь зберегти як `review/done-001.json`, потім:

```bash
python3 tools/import-cards.py review/done-*.json
```

Приймач той самий, що й для наповнення — він однаково лагодить мовні
покручі й не дає зіпсованому перезаписати добре.

## Промт (копіювати цілком)

```
Ти редагуєш готові картки фільмів і серіалів для української медіатеки.
Матеріалу шукати не треба — все, що потрібно, вже є в самій картці.

# Що не так

1. ТАВТОЛОГІЯ. Поле "worth" часто повторює те саме, що вже сказано у
   "for" і "not_for" — трьома реченнями переказує одну думку. Приклад
   поганого набору:

     worth:   "Якщо цікавить альтернативна версія історії Людини-павука
               з іншими менторами, серіал може сподобатися."
     for:     "Для фанатів мультивсесвіту Marvel та історій про
               походження героїв."
     not_for: "Для тих, хто очікує знайомого сюжету з основного
               Кіновсесвіту."

   Тут "worth" не додає нічого нового понад "for"/"not_for" — це та сама
   інформація, сказана втретє. "worth" має нести ОКРЕМУ думку: чи варто
   загалом, і чому саме — рівень якості, тон, що вирізняє серед подібного.
   "for"/"not_for" — про аудиторію. Якщо після редагування "worth" можна
   видалити без втрати сенсу — воно було зайвим.

2. ПЕРЕКРУЧЕНІ СЛОВА. Модель зрідка зрощує слова або губить літери:
   "супергемерських" замість "супергеройських". Шукай такі спотворення
   в усіх текстових полях і виправляй на нормальне слово.

3. ПУСТІ ОПИСИ ОЦІНОК. "complexity"/"violence"/"erotica"/"children" мають
   description, яке пояснює ЧОМУ такий бал — не просто повторює слово з
   балу. Погано: "Помірна складність." (нічого не додає до самого числа).
   Добре: "Може бути трохи заплутаним через елементи мультивсесвіту та
   часових парадоксів." (конкретна причина).

# Чого НЕ робити

- Не шукай нових фактів і не додавай нічого, чого немає в картці —
  редагування, не наповнення.
- Не чіпай "ending_explained", "easter_eggs", "source", "id", "kind",
  "year", "title" — поверни їх ТОЧНО як у вхідних даних, символ у символ.
- Якщо в картці "worth"/"for"/"not_for"/"mood"/оцінки вже добрі й без
  тавтології — лиши як є, не редагуй заради редагування.
- Мова лишається українською, без кальок і канцеляриту (як і раніше:
  «глядач», не «глядатель»; без «Рекомендується для…»).
```

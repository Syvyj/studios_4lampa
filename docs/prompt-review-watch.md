# Промт: панель «Чи варто дивитись?»

Модель отримує лише назву, рік і опис — і пише панель. Ні фіналу, ні
фактів, ні джерела в пачці немає, тому зіпсувати їх фізично неможливо:
`merge-watch.py` вписує назад тільки шість полів панелі, решту картки бере
з диска.

Через це в промті немає жодного «не чіпай того-то» — нічого зайвого й не
надсилається.

## Кроки

```bash
python3 tools/make-review-batches.py --size 40
```

Далі — новий чат на кожну пачку, промт нижче, прикріпити `review/batch-001.json`.
Відповідь зберегти як `review/done-001.json` (або кинути прямо в чат Claude), потім:

```bash
python3 tools/merge-watch.py review/done-001.json
```

## Промт (копіювати цілком)

```
Ти — редактор української медіатеки. Даю список фільмів і серіалів: назва,
рік, короткий опис. Для кожного напиши панель «Чи варто дивитись?».

# Що написати

{
  "id": 1234,            // скопіюй із вхідних даних
  "kind": "movie",       // скопіюй
  "title": "Назва",      // скопіюй
  "watch": {
    "worth": "Чи варто дивитись і чим ця річ вирізняється. Одне-два речення.",
    "for": "Кому підійде.",
    "not_for": "Кому не підійде."
  },
  "mood": ["3-5 слів про настрій"],
  "complexity": {"score": 1, "description": "Наскільки складно дивитись і чому саме."},
  "violence":   {"score": 0, "description": "Скільки жорстокості і в чому вона."},
  "erotica":    {"score": 0, "description": "Скільки відвертих сцен."},
  "children":   {"recommended": false, "description": "Чи підійде дітям і чому."}
}

Оцінки: 0 — немає зовсім, 5 — дуже багато. Складність від 1 до 5.

# Три правила, які вирішують усе

1. WORTH — ОКРЕМА ДУМКА, НЕ ПЕРЕКАЗ. Найчастіша помилка: "worth" каже те
   саме, що потім "for" і "not_for", лише іншими словами. Так не можна:

     worth:   "Якщо цікавить альтернативна історія Людини-павука з іншими
               менторами, серіал може сподобатися."
     for:     "Фанатам мультивсесвіту Marvel та історій про походження героїв."

   Це одна думка, сказана двічі. "worth" — про саму річ: що в ній
   особливого, який тон, чим вирізняється серед подібного. "for"/"not_for" —
   про аудиторію. Перевір себе: якщо "worth" можна видалити й нічого не
   загубиться — воно було зайве, перепиши.

2. ОПИС ОЦІНКИ ПОЯСНЮЄ ПРИЧИНУ, А НЕ ПОВТОРЮЄ ЧИСЛО.
   Погано: "Помірна складність." — нічого не додає до самого балу.
   Добре:  "Заплутано через стрибки в часі й кількох оповідачів."

3. СУДИ ЗА ОПИСОМ, НЕ ВИГАДУЙ СЮЖЕТ. Оцінки й настрій — це твоє судження
   на основі опису, тут вигадка неможлива. Але не додавай подій, імен чи
   деталей, яких в описі немає.

# Мова

Природна українська, як говорить жива людина:
- «глядач», а не «глядатель»; «шанувальник», а не «поклонник»
- без активних дієприкметників: «захопливий», а не «захоплюючий»
- без канцеляриту: не «рекомендується для любителів жаху», а «для тих,
  хто любить жахи»
- без рекламних зворотів: жодних «шедевр», «маст-вотч», «неймовірний»
```

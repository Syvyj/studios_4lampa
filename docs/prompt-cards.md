# Промт для наповнення бази карток

Два готові тексти: перший — для агента, який пише файли сам (Gemini CLI тощо),
другий — для NotebookLM, який файлів не пише, але добре складає таблицю.

---

## 1. Для агента (пише картки у файли)

```
Ти наповнюєш базу карток фільмів і серіалів для української медіатеки «Ліхтар» —
плагіна до Lampa. Картки читає плагін напряму з файлів, бази й сервера немає.

# Де що лежить

Тека: /Users/admin/Projects/studios_4lampa-dev/cards/
  фільм   → <tmdb_id>.json        напр. 1084242.json
  серіал  → tv<tmdb_id>.json      напр. tv202555.json
  індекс  → index.json            {"ids":[...фільми...],"tv":[...серіали...],"updated":"РРРР-ММ-ДД"}

У TMDB нумерація фільмів і серіалів окрема, тому серіали мають префікс tv:
без нього фільм 1399 затер би серіал 1399.

Файли — UTF-8, без екранування кирилиці (ensure_ascii=false), без Markdown,
без коментарів. Один файл — один валідний JSON-обʼєкт.

# Формат картки

{
  "summary": "Про що, без спойлерів. До 400 символів.",
  "watch": {
    "worth": "Чи варто дивитись і чому. Одне-два речення.",
    "for": "Кому підійде.",
    "not_for": "Кому не підійде."
  },
  "mood": ["3-5 слів про настрій"],
  "complexity": {"score": 1..5, "description": "Наскільки складно дивитись."},
  "violence":   {"score": 0..5, "description": "Скільки жорстокості."},
  "erotica":    {"score": 0..5, "description": "Скільки відвертих сцен."},
  "children":   {"recommended": true|false, "description": "Чи підійде дітям."},
  "ending_explained": "Пояснення фіналу, 300-700 символів. Для серіалу — лише якщо історію завершено.",
  "easter_eggs": ["3-5 конкретних фактів про створення: імена, числа, назви"],
  "id": 1084242,
  "kind": "movie" | "tv",
  "title": "Назва українською як у TMDB",
  "year": "2025",
  "source": {"wiki": "Назва статті", "lang": "uk"} | null,
  "generated": "РРРР-ММ-ДД"
}

Мова всіх текстів — українська, природна, без рекламних зворотів
(«шедевр», «неймовірний», «маст-вотч»). Пиши як редактор, не як афіша.

# Головне правило: жодного вигадування

Сюжет, фінал і факти про створення бери ВИКЛЮЧНО з джерел, які ти справді
прочитав: стаття Вікіпедії про цю назву, опис TMDB, матеріали студії, преса.
Якщо джерела немає — став порожній рядок або порожній масив. Порожнє поле це
нормальний результат, вигадане — брак.

Виняток — оцінки (складність, насильство, еротика, діти, настрій): це твоє
судження на основі матеріалу, тут порожнеча не потрібна.

Перед записом перевір кожне твердження: чи є воно в джерелі. Якщо факт «схоже
на правду», але в тексті його немає — прибери.

# Чого не робити (набито на попередньому прогоні)

1. НЕ БРАТИ СТАТТЮ ПРО ІНШИЙ ТВІР. Пошук завжди щось повертає. На «Друзі та
   сусіди» Вікіпедія віддала статтю про «Друзі», на «Casa Grande» — про
   «Паперовий будинок», на «Велике пробудження» — про «Зоряні війни:
   Пробудження сили». З них вийшли картки з упевнено переказаним чужим
   сюжетом. Перед використанням статті звір: назва, рік випуску і тип (фільм
   чи серіал) мають збігтися з TMDB. Не збіглося — вважай, що джерела немає.
2. Уточнення в дужках у назві статті («(фільм)», «(телесеріал)», «(2026)») —
   не розбіжність, їх ігноруй. Так само «ґ» і «г»: «Аанґа» і «Аанга» — одне.
3. Для неанглійських назв шукай англійську статтю за АНГЛІЙСЬКОЮ назвою з
   TMDB, а не за оригінальною: стаття про «പ്രകമ്പനം» називається
   «Prakambanam», і за оригінальним написанням ти її не знайдеш.
4. Серіал, який триває, фіналу не має — лиши "ending_explained" порожнім.
   Не переказуй фінал останнього сезону як фінал історії.
5. Уникай фраз, якими прикривають незнання: «фінал залишає простір для
   інтерпретацій», «кожен глядач вирішить сам», «можна трактувати по-різному».
   Це ознака того, що сюжету ти не знайшов — тоді поле має бути порожнім.
6. Опис українською в TMDB часто порожній — бери англійський, але переказуй
   українською.
7. Ток-шоу, новини й реаліті пропускай: у них немає ні сюжету, ні фіналу.

# Що робити

1. Візьми список назв (див. нижче) або сформуй його з TMDB:
   discover/movie?primary_release_year=РІК&vote_count.gte=20&sort_by=popularity.desc&language=uk
   discover/tv?first_air_date_year=РІК&vote_count.gte=20&sort_by=popularity.desc&language=uk&without_genres=10763,10764,10767
2. Для кожної назви: збери джерела → перевір, що вони саме про неї → склади
   картку → запиши у файл за іменем вище.
3. Файл, який уже існує, не чіпай, якщо в ньому є "source" і непорожні
   "ending_explained" або "easter_eggs". Порожні перезаписуй.
4. Наприкінці перебудуй index.json з наявних файлів.

# Самоперевірка перед записом

- JSON валідний, усі поля на місці, score у межах.
- Кожне імʼя, число й назва в "easter_eggs" є в джерелі.
- "ending_explained" описує події, а не враження.
- Назва статті-джерела справді про цю назву й цей рік.
- Текст читається українською, а не як переклад.

# Обсяг

Тека вже містить:
  фільми 2026 — 876 карток (з них 166 із чужою статтею, їх треба перезаписати)
  фільми 2025 — 298
  серіали 2025 — 299 (лише 79 мають джерело — решту варто добрати)
```

### Приклад готової картки

Це реальний файл із бази — орієнтуйся на глибину фіналу й конкретність фактів:

```json
{
  "summary": "Музична кіноадаптація історії Білосніжки та Злої Королеви…",

  "easter_eggs": ["31 жовтня 2016 року студія оголосила…"]

```

## 2. Для NotebookLM (складає таблицю)

NotebookLM не пише файли й не ходить у TMDB — він працює з тим, що ви в нього
завантажили. Тому схема така: він робить таблицю, а конвертує її у картки
окремий скрипт.

Спершу завантажте джерела (статті Вікіпедії про потрібні назви), потім:

```
Склади таблицю по кожному твору з завантажених джерел. Колонки:

назва | рік | тип (фільм/серіал) | про що (до 400 символів, без спойлерів) |
чи варто дивитись | кому підійде | кому не підійде | настрій (3-5 слів через кому) |
складність 1-5 | насильство 0-5 | еротика 0-5 | дітям (так/ні) |
пояснення фіналу (300-700 символів; для серіалу, що триває — порожньо) |
факти про створення (3-5 штук через крапку з комою: імена, числа, назви)

Правила:
- Усе бери виключно з завантажених джерел. Чого немає — лиши клітинку порожньою.
- Порожня клітинка краща за здогад.
- Оцінки й настрій — твоє судження, їх заповнюй завжди.
- Мова українська, без рекламних зворотів.
- Не змішуй твори зі схожими назвами: звіряй рік.
```

Готову таблицю експортуйте у CSV — перетворити її на картки з правильними
іменами файлів нескладно, скажіть, і я допишу конвертер `tools/csv-to-cards.py`
(йому потрібні tmdb_id, які він добере пошуком за назвою і роком).
